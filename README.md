\# 🛒 Smart Minimart



A full-stack e-commerce web application built using \*\*React.js\*\*, \*\*Node.js\*\*, \*\*Express.js\*\*, and \*\*MySQL\*\*. Smart Minimart provides a seamless online shopping experience with secure authentication, cart management, wishlist, order management, and an admin dashboard.



\---



\## 📌 Features



\### 👤 User Features



\* User Registration \& Login

\* JWT Authentication

\* Browse Products

\* Product Details Page

\* Search Products

\* Add to Cart

\* Update Cart Quantity

\* Remove Items from Cart

\* Wishlist Management

\* Checkout

\* Place Orders

\* View Order History

\* Recently Viewed Products



\### 👨‍💼 Admin Features



\* Admin Dashboard

\* Product Management (Add, Update, Delete)

\* User Management

\* Order Management

\* Coupon Management

\* Sales Analytics

\## 🚀 Installation



\### 1. Clone the Repository



```bash

git clone https://github.com/anuradha-mudhale/Smart-Minimart.git

cd Smart-Minimart

```



\---



\### 2. Install Backend Dependencies



```bash

cd Backend

npm install

```



\---



\### 3. Install Frontend Dependencies



```bash

cd ../frontend

npm install

```



\---



\## ▶️ Run the Application



\### Start Backend



```bash

cd Backend

npm start

```



\---



\### Start Frontend



```bash

cd frontend

npm run dev

```
